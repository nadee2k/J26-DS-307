What this demo collects

Live session: counts of key presses, pointer distance and clicks, idle time, and whether this demo tab is visible. It never records typed characters.

Scope: browser-page metadata only. It cannot monitor activity in other applications or infer that a learner is concentrating.

Storage: snapshots are held in this page until you end the session, then kept in server memory for up to 12 hours. They are not saved to the database.

Sample session: generated example events, clearly marked as demonstration-only, processed by the selected trained Component 1 model.

Session outcomes

Component 1 demo · Interaction states describe observed behaviour patterns, not validated focus or distraction labels.
