Labelling approach

          

            
Interaction states are discovered unsupervised from behavioural features only (keyboard, mouse, application, temporal). No concentration ratings are used to form clusters.

            
Session-level ground truth comes from participants’ self-reported concentration ratings (concentration_logs.level, 1–5), aggregated per session for supervised evaluation.

            

          

        

        

          
Separation of concerns

          

            
    
              
  • Objective/behavioural: events → features → unsupervised states → transitions/context (representation)
    • 
              
  • Subjective (aggregated): self-reports → session mean → rounded label (target for baseline/proposed/ablations)
    • 
            

            
The label is not used in state discovery, transition computation, or window feature extraction. It’s only the evaluation target (plus descriptive context-effect summaries).
